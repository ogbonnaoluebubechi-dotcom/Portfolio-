# Client Onboarding System 
A Clickup based workflow designed to organize client Onboarding System.
## Project Overview 
This project demonstrate how i used Clickup to create a client Onboarding System, assigned task to teammates and and made sure tasks are done in a sequential manner.
## Tool Used 
ClickUp 
## Features demonstrated
- Task Priorities
- Task Organization 
- Due Dates
- Dependencies
