# CEO Operations Dashboard
A Trello-based dashboard designed to organize tasks, priorities, deadlines, checklists, and team coordination.
## Project Overview
This project demonstrates how I use Trello to create a structured workflow for managing a CEO's tasks and responsibilities.
## Tools Used
- Trello
## Features Demonstrated 
- Checklists
- Due Dates
- Task Priorities
- Team Assignment
